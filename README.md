# Golf Swing

A simple web app (PWA) for the driving range: set your phone up, tap start, and it loops hands-free:

**countdown → record your swing → replay it (with slow-mo) → countdown again**, until you tap stop.

- Uses the phone's front camera so you can watch the replay from where you stand
- Countdown beeps so you know when recording starts
- Slow-motion replays (last replay or all, at ¼×, ½× or ¾×)
- Adjustable countdown, recording length, number of replays, pause between replays, video quality and frame rate
- Keeps the screen awake during a session
- Videos stay on the phone and are never uploaded

## Install on Android

1. Open the app link in Chrome.
2. Allow camera access.
3. Chrome menu (⋮) → **Add to Home screen** / **Install app**.

Hosted with GitHub Pages from the `main` branch.
